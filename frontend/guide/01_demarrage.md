# 1. Démarrage : connexion, mot de passe, navigation

## À quoi ça sert
Cette fiche vous apprend à **entrer dans l'application**, à **retrouver votre mot de passe**,
et à **vous repérer** dans les menus. C'est la base : lisez-la en premier.

## Se connecter (pas à pas)
1. Ouvrez votre navigateur (Chrome, Firefox…) et allez sur l'adresse de l'application
   (ex. `https://agrivision-pro-next.netlify.app`).
2. Vous arrivez sur la page **Connexion**.
3. Tapez votre **adresse email** et votre **mot de passe**.
4. Cliquez sur **Se connecter**.
5. Vous arrivez sur le **Dashboard** (tableau de bord). C'est gagné.

> 💡 Si rien ne se passe ou que la page semble figée : faites **Ctrl + F5** (recharge complète).

## Créer un compte (première fois)
1. Sur la page de connexion, cliquez sur **Créer un compte**.
2. Remplissez : email, mot de passe (6 caractères minimum), rôle, **nom de la coopérative**, pays.
3. Cliquez pour valider.

> ⚠️ **Règle importante** : la **première personne** qui inscrit une coopérative devient
> automatiquement **Administrateur** (c'est le fondateur). Les personnes suivantes choisissent
> leur rôle (Agronome ou Technicien) — le rôle Admin ne peut pas être pris tout seul ensuite,
> c'est l'admin existant qui le donne.

## J'ai oublié mon mot de passe
1. Page de connexion → cliquez sur **« Mot de passe oublié ? »**.
2. Saisissez votre email → **Envoyer le lien**.
3. Vous recevez un **email** avec un lien (valable 1 heure) → cliquez dessus.
4. Choisissez un **nouveau mot de passe** (2 fois) → vous êtes redirigé vers la connexion.

> Si l'envoi d'email n'est pas encore activé chez vous, l'écran affiche directement le lien
> de réinitialisation (utile pour dépanner l'administrateur). Sinon, un autre administrateur
> de la coopérative peut réinitialiser votre mot de passe depuis **Administration**.

## Changer mon mot de passe (quand je suis connecté)
- En bas à gauche, à côté de votre nom, cliquez sur l'icône **clé** 🔑 → saisissez l'ancien
  et le nouveau mot de passe.

## Se repérer dans l'écran
- **À gauche** : le **menu** (Dashboard, Plantations, Diagnostic, Carte…). Cliquez pour changer de page.
- **En haut** : le **titre** de la page et les **boutons d'action** (ex. *Ajouter*, *Importer*, *Actualiser*).
- **En bas à gauche** : votre **nom/rôle**, la **clé** (mot de passe) et la **flèche de déconnexion**.
- **En bas à droite** : une **cloche** 🔔 pour les notifications.

## Se déconnecter
- Cliquez sur la **flèche de déconnexion** (en bas à gauche). Vous revenez à la page de connexion.

## Sur téléphone / tablette
- L'application s'adapte. Le menu peut se replier : touchez l'icône **menu** (☰) pour l'ouvrir.
- Elle fonctionne même **hors ligne** pour certaines saisies (elles seront envoyées au retour du réseau).

## En cas de problème
| Problème | Solution |
|---|---|
| Page blanche / figée | **Ctrl + F5** pour recharger. |
| « Identifiants incorrects » | Vérifiez l'email et le mot de passe (attention aux majuscules). |
| Déconnecté tout seul | Reconnectez-vous ; la session se renouvelle normalement toute seule. |
| Un module a disparu du menu | Votre **plan d'abonnement** ne l'inclut pas — contactez votre administrateur. |

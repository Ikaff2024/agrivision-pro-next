Chaque donnée collectée → son standard → sa structure de référence

Objectif (recommandation ICI) : pour chaque module, savoir sur quel standard la donnée s'appuie et quelle structure le définit — afin d'engager la validation formelle. Statut : aligné = construit selon le cadre · à valider = alignement à faire confirmer par la structure · limite = à ne pas surclamer.

Comment l'utiliser. Ce référentiel est un état déclaratif : « aligné » signifie que le module est construit selon le cadre, pas qu'une structure l'a certifié. La démarche recommandée par ICI = faire confirmer chaque ligne « à valider » par la structure concernée (ICI pour le CLMRS/SSRTE, CNRA/CIRAD pour l'agronomie, LICOP pour le revenu vital, ARTCI pour les données). Assumer les limites (carbone estimé) est un gage de crédibilité, pas une faiblesse.
